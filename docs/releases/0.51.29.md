# 0.51.29 正式版

修复 Android 图片聊天在启动、保存或重开历史时因原生文件接口处理大段图片数据而发生的内存溢出闪退。

- 图片原数据在当前 Vault 内无损分块保存，相同数据去重；会话文件保存引用，重开时校验并恢复原图。
- 历史列表逐个读取，读取旧大文件前检查大小；图片缺失、保存失败及过量请求明确提示，不静默压缩或丢弃图片。
- 手机 OpenAI-compatible 请求整体超过 16 MiB 时提示分批发送或新建会话，保留原记录。

唯一功能基线：用户已验收的 0.51.29-imagefix-test.1，提交 c6374ed232addd0b3af60108234d9f8220db37c2。本次仅更新版本号、发布说明及元数据，不修改功能代码；main.js、styles.css 与该测试版逐字节一致。

原测试版验证记录：48 项定向单元检查及 1 项真实 Obsidian 移动界面仿真通过；用户随后确认检查通过并批准正式发布。本次核验正式构建、版本一致性、附件哈希和 ZIP 内容，不重复功能验收。

此前已隔离的超大会话仍保留备份，本版不自动恢复。新保存的图片会话备份需包含整个 sessions 目录及 media 子目录。旧版不理解新的图片引用，回退前应保留当前完整数据，且不要直接恢复导致闪退的旧大文件。

BRAT 仓库：nq980926-source/azhen-agentic-chat-zh；正式版本：0.51.29。保留正式版 0.51.27 和已验收测试版的 Release 及附件。

没有更改 COS 项目、服务器、Knowledge MCP、Memory、Syncthing 或其他插件。
