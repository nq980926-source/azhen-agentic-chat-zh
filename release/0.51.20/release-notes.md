# Agentic Chat 0.51.20 阿斟简体中文版

- Android/移动端 Enter 交给原生 textarea 换行，组合输入不触发提交；Windows Enter 发送、Shift+Enter 换行。
- 工具栏新增“添加图片”，使用系统文件选择器；支持 PNG/JPEG/WebP/GIF，多图缩略图、移除、内容去重。
- 最多 4 张，每张 10 MB、总计 20 MB；校验格式签名和浏览器解码，格式/大小/读取错误明确提示。
- 复用 ImageContent、AgentService 和现有会话存储，真实图片和文字同次发送。不支持视觉时明确拦截，不自动切换模型。
- 图片发送失败保留文字和图片草稿；成功及历史回放显示图片；重试携带原消息图片。
- 运行中图片消息需等待当前回复结束后发送；图片消息不支持文字改写，支持重试或重新选择图片发送。
- 选图只存于当前标签页内存，关闭插件或应用前请发送；不写入 Vault、Knowledge MCP 或独立云存储。
- 插件 ID agentic-chat、最低版本 1.11.4 保持不变。保留历史版本、MIT 和第三方声明。无需迁移配置、历史或 SecretStorage。

验证：TypeScript、生产构建、移动兼容和修改文件 ESLint 通过。定向回归 94 项通过；本地 Obsidian 1.15.0 的 7 项 DOM/事件断言通过（合成 File 选择，未调用真实模型）。全量测试的原有 7 项失败和 3 个套件加载错误在 0.51.19 基线复现。

尚待实测：Windows/Android 原生文件或相册选择器、Android 连续换行和中文输入法、视觉模型真实响应。没有 Android 实机验收，不将桌面模拟或单元测试等同于实机通过。标准 WDIO 启动受远程版本索引 fetch 失败阻断，已用本地 Obsidian 隔离仓库补测。
